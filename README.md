# Node.js Backend — интерактивный учебник

Интерактивный учебник для подготовки к собеседованию на Middle Node.js-разработчика: симуляторы, диаграммы, песочницы, задачи и тесты. Интерфейс на русском.

Учебный план и план реализации: см. `docs/`.

## Быстрый старт

```bash
npm install
npm run dev            # режим разработки
npm run build          # статический сайт в dist/
npm run build:single   # один HTML-файл в dist-single/index.html (открывается двойным кликом)
npm test               # тесты движка, сверка модели с реальным Node.js
npm run e2e            # сквозная проверка в браузере (нужен Chrome, npm run build и npm run preview)
npm run gen:labs       # пересобрать файлы лабораторий из сценариев
```

## Структура

```
src/app/          оболочка: навигация, темы, прогресс, страницы
src/components/   симуляторы, песочница, тесты, карточки задач
src/content/      модули, уроки и сценарии (данные, не вёрстка)
src/engine/       движки симуляций и запуск кода в Web Worker
labs/             задания для локального запуска (Node.js, Docker)
tools/            генерация лабораторий, e2e-проверка
docs/             учебный и реализационный планы
```

## Режимы практики

- 🌐 **В браузере** — выполняется на странице.
- 💻 **Локально** — нужно запустить на своём компьютере (`labs/`).
- 🔀 **Гибрид** — модель в браузере плюс проверка на реальной системе.
