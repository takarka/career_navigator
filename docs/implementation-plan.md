# План реализации: интерактивный учебник «Node.js Middle Backend»

Статус: **только план, разработка не начата.**
Основа: файл `nodejs-interview-study-plan.md` (15 модулей, около 70 задач).

---

## 1. Цель и принципы

**Цель:** сайт-учебник на русском, по которому можно пройти весь учебный план от модуля 0 до 14: читать, трогать диаграммы, смотреть симуляции, решать задачи и проверять себя.

**Принципы**
1. **Показывай, а не рассказывай.** Каждый урок содержит минимум один интерактивный элемент: диаграмму, симулятор или песочницу.
2. **Честная граница модели и реальности.** Симулятор в браузере показывает идею, но не заменяет реальный брокер или БД. Каждая модель помечена значком «модель», рядом лежит ссылка на локальную практику.
3. **У каждой практической задачи видно, где её делать:** 🌐 в браузере, 💻 локально, 🔀 гибрид.
4. **Всё привязано к собеседованию.** В каждом уроке есть блок «Как это спросят» и «Как ответить», а в конце тест на самопроверку.
5. **Контент отделён от кода.** Уроки описываются данными, а не вручную вёрстаются. Так модули можно делать по очереди и править без переписывания движка.
6. **Точность важнее скорости.** Результаты примеров с кодом получаются реальным запуском Node.js на этапе сборки, а не пишутся «по памяти».

## 2. Анализ учебного плана: что где можно показать

Все темы плана делятся на три класса по тому, как их можно сделать интерактивными.

### Класс A. Полностью в браузере (реальное исполнение)
Браузер исполняет настоящий код, результат точный.

- JavaScript и async-паттерны (модули 1, 2): песочница с тестами.
- TypeScript: проверка типов в браузере через компилятор TypeScript.
- **PostgreSQL:** настоящий Postgres в браузере через WebAssembly (PGlite). Работают `EXPLAIN ANALYZE`, индексы, транзакции, JSON, миграции.
- Web Workers (демонстрация блокировки главного потока и выноса вычислений).
- WebCrypto: хеши и подписи для демонстрации XML-DSig, JWT.
- Разбор XML и WSDL через встроенный парсер браузера.

### Класс B. Симулятор в браузере плюс реальная практика локально
Реальную систему в браузере не запустить, поэтому делаем визуальную модель и отдельное задание для компьютера.

- Event loop Node.js (порядок фаз, `nextTick`, `setImmediate` нельзя воспроизвести точно в браузере).
- Redis: свой мини-Redis на JS с терминалом и ускоренными часами для TTL.
- RabbitMQ и Kafka: визуальные модели маршрутизации, партиций, consumer groups, ack, ретраев, DLQ.
- Изоляция транзакций и дедлоки: сценарий двух сессий по шагам. PGlite работает с одним соединением, поэтому конкурентность показываем моделью, а настоящий опыт даём локально через два `psql`.
- Streams и backpressure, graceful shutdown.
- Микросервисы, circuit breaker, масштабирование, нагрузка и латентность.
- Docker: слои, кэш сборки, порядок запуска compose.
- NestJS: DI-контейнер, жизненный цикл запроса.
- Outbox, Inbox, Saga.
- SOAP, XML-DSig, цепочка сертификатов, каналы ШЭП (схемы и модели).

### Класс C. Только локально
Требуют реальных процессов, сети или проприетарных компонентов.

- Запуск NestJS-приложения, тесты с контейнерами.
- Реальные Kafka и RabbitMQ в docker compose.
- Профилирование и нагрузочные тесты (`--inspect`, autocannon, k6, clinic).
- Реальная подпись через NCANode и Kalkan, вызовы настоящих SOAP-сервисов.
- Два параллельных `psql` для воспроизведения аномалий изоляции.
- Миграции с ORM, N+1 на реальной связке.

Для класса C в учебнике будут пошаговые карточки: что установить, какие команды запустить (с кнопкой «копировать»), что должно получиться и как проверить.

## 3. Матрица модулей: уроки, интерактив, режим практики

Обозначения: 🌐 в браузере, 💻 локально, 🔀 гибрид (модель в браузере плюс реальный запуск).

### Модуль 0. Диагностика и окружение (2 урока)
- Интерактив: радар самооценки по требованиям вакансии, мастер проверки окружения (чек-лист команд).
- Практика: 🌐 0.1, 0.4; 💻 0.2, 0.3.

### Модуль 1. Node.js: ядро (6 уроков)
Уроки: архитектура, event loop, блокировка цикла, Events, Streams, ошибки и завершение.
- Симулятор event loop: фазы, очереди macro и microtask, `nextTick`. Режим «угадай вывод» с эталонами из реального запуска.
- Симулятор streams: ползунки `highWaterMark` и скорости читателя, наглядный backpressure.
- Демо блокировки: живой индикатор «кадров в секунду» при тяжёлом вычислении и перенос в Web Worker.
- Демо утечки слушателей EventEmitter.
- Таймлайн graceful shutdown.
- Практика: 🌐 1.1; 🔀 1.2, 1.3, 1.4; 💻 1.5.

### Модуль 2. JavaScript и TypeScript (4 урока)
- Интерактив: визуализатор замыканий, `this` и цепочки прототипов; таймлайн `Promise.all`, `allSettled`, `race`; TypeScript-головоломки с проверкой типов; мини-тесты для кода.
- Практика: 🌐 2.1, 2.2, 2.3, 2.4.

### Модуль 3. PostgreSQL (7 уроков)
Уроки: схема, индексы, транзакции и MVCC, изоляция, блокировки, EXPLAIN, пагинация и миграции.
- Песочница SQL на реальном Postgres в браузере с готовым датасетом.
- Визуализатор B-tree: вставка, поиск, влияние порядка колонок в составном индексе.
- Визуализатор плана EXPLAIN ANALYZE: дерево узлов, оценка против факта.
- Визуализатор MVCC: версии строк (`xmin`, `xmax`).
- Сценарии изоляции: две сессии на таймлайне, пошагово, с выбором уровня изоляции.
- Симулятор дедлока.
- Сравнение offset и keyset на большом датасете (замер времени в браузере).
- Практика: 🌐 3.1, 3.2, 3.5; 🔀 3.3, 3.4, 3.6; 💻 3.7.

### Модуль 4. Redis (5 уроков)
Уроки: структуры, cache-aside, инвалидация и проблемы кэша, rate limiting, атомарность и блокировки.
- Терминал мини-Redis: основные команды, `EXPIRE`, структуры, Lua-подобные сценарии, часы с ускорением.
- Симулятор кэша: поток запросов, hit/miss, stampede, эффект jitter и блокировки.
- Визуализатор rate limiter: fixed window, sliding window, token bucket на одном потоке запросов.
- Практика: 🌐 4.5; 🔀 4.1, 4.2, 4.3, 4.4.

### Модуль 5. REST API и WebSocket (5 уроков)
Уроки: REST и идемпотентность, формат ошибок, авторизация и JWT, OpenAPI, WebSocket.
- Интерактив: справочник статус-кодов с кейсами, декодер JWT, песочница мок-API (идемпотентный POST), симулятор WebSocket (heartbeat, обрыв, переподключение), схема масштабирования через pub/sub.
- Практика: 🌐 5.1; 🔀 5.2, 5.4, 5.5; 💻 5.3.

### Модуль 6. NestJS (5 уроков)
Уроки: модули и DI, жизненный цикл запроса, DTO и валидация, БД и конфигурация, сравнение с Express.
- Интерактив: визуализатор DI-контейнера (граф провайдеров, области видимости), аниматор жизненного цикла (включай и выключай guard, pipe, interceptor и смотри, где запрос останавливается), сравнение кода Express и NestJS бок о бок.
- Практика: 💻 6.1–6.5. Для каждой задачи будут стартовые файлы и автотесты.

### Модуль 7. Docker и compose (3 урока)
- Интерактив: симулятор слоёв и кэша сборки (меняй порядок инструкций и смотри пересборку), калькулятор размера multi-stage, граф зависимостей compose с анимацией порядка запуска и healthcheck.
- Практика: 🔀 7.1; 💻 7.2, 7.3.

### Модуль 8. Брокеры сообщений (8 уроков)
Уроки: зачем брокеры, RabbitMQ, Kafka, гарантии доставки, идемпотентность, ретраи и DLQ, Outbox и Inbox, Saga.
- Симулятор RabbitMQ: редактор exchange и binding, типы exchange, ack/nack, prefetch, TTL и DLX.
- Симулятор Kafka: партиции, ключи, consumer groups, rebalance, коммит offset, lag, replay.
- «Инжектор сбоев»: убей consumer до ack и посмотри на дубли, затем включи идемпотентность.
- Визуализатор Outbox: транзакция, relay, повторная публикация.
- Оркестратор Saga: шаги, сбой, компенсации.
- Практика: 💻 8.1, 8.2, 8.4, 8.5; 🔀 8.3, 8.6, 8.7.

### Модуль 9. Архитектура (5 уроков)
- Интерактив: холст «собери систему» (сервисы, синхронные и асинхронные связи, отключение сервиса, каскад отказов, включение circuit breaker), задания на рефакторинг по SOLID (до и после), симулятор масштабирования под нагрузкой.
- Практика: 🌐 9.1, 9.2, 9.4, 9.5; 🔀 9.3.

### Модуль 10. Производительность (4 урока)
- Интерактив: визуализатор перцентилей (p50, p95, p99), кривая «загрузка и задержка» (очереди), интерактивный flame graph на готовых профилях, график роста heap при утечке.
- Практика: 💻 10.1, 10.2, 10.3; 🌐 10.4 (шаблон отчёта).

### Модуль 11. Тестирование (3 урока)
- Интерактив: пирамида тестов, сравнение mock, stub, spy на живом примере, мини-раннер тестов для JS-задач.
- Практика: 🌐 11.1; 💻 11.2, 11.3, 11.4.

### Модуль 12. SOAP, ШЭП, Kalkan (6 уроков)
Уроки: SOAP и WSDL, клиенты SOAP, ШЭП и каналы, XML-DSig и CMS, Kalkan и сертификаты, надёжность интеграций.
- Интерактив: просмотрщик и конструктор SOAP по WSDL (в том числе Fault), интерактивное дерево XML-подписи (меняй содержимое документа и смотри, как ломается digest на реальном SHA-256), сравнение XML-DSig и CMS, симулятор проверки цепочки сертификатов (срок, OCSP, CRL), аниматор синхронного и асинхронного канала.
- Практика: 💻 12.1, 12.2; 🔀 12.3, 12.5; 🌐 12.4, 12.6.
- **Важно:** детали ШЭП и Kalkan будут сверяться с официальной документацией. Всё, что нельзя подтвердить источником, помечается как «уточнить».

### Модуль 13. Capstone (2 урока-гида)
- Интерактив: пошаговый чек-лист проекта, схема архитектуры, шаблон репозитория, критерии приёмки каждого этапа.
- Практика: 💻 13.1–13.6; 🌐 13.7.

### Модуль 14. Подготовка к собеседованию (5 уроков)
- Интерактивный режим мок-интервью: один вопрос за раз, пишешь ответ, затем открывается эталон и рубрика самооценки 1–10.
- Конструктор STAR-историй, карточки вопросов с интервальным повторением, чек-лист system design, шаблон зарплатных переговоров.
- Практика: 🌐 14.1–14.10 (часть задач можно переносить в чат со мной для разбора ответов).

**Итого:** около 70 уроков и около 70 практических задач.

## 4. Техническая архитектура

### 4.1 Стек
- **Vite + TypeScript** для сборки, **Preact** для интерфейса (лёгкий, подходит для множества интерактивных виджетов).
- **CSS-переменные**, светлая и тёмная темы, адаптив под телефон и ноутбук.
- **SVG и CSS-анимации** для схем; **d3** только там, где он нужен (flame graph, графики).
- **CodeMirror 6** вместо Monaco: легче, лучше работает на телефоне.
- **PGlite** (Postgres в WebAssembly) для модуля 3, подгружается только на уроках с SQL.
- **Компилятор TypeScript** в браузере для проверки типов, подгружается лениво.
- **Mermaid** только для простых статичных диаграмм.

### 4.2 Структура проекта
```
textbook/
  src/
    app/            оболочка: навигация, поиск, прогресс, темы
    content/        данные уроков (по модулям)
      m01-node-core/
        lessons/*.ts
        quizzes/*.ts
        tasks/*.ts
    components/
      blocks/       текст, callout, код, вопрос собеседования
      sim/          симуляторы (общий движок + конкретные)
      sandbox/      JS, TS, SQL песочницы
      practice/     карточка задачи (🌐/💻/🔀)
      quiz/         тесты, карточки, мок-интервью
    engine/         SimPlayer, часы, раннер тестов, воркеры
  labs/             локальные лаборатории по модулям
    docker-compose.yml
    m01/ ... m13/   стартовые файлы + автотесты
  tools/
    record-traces/  запуск реального Node для эталонных результатов
  dist/             готовая сборка
```

### 4.3 Формат урока
Урок описывается данными из блоков:
`заголовок → зачем это нужно → ментальная модель → интерактив → типичные ошибки → «как спросят» → тест → задача`.

Типы блоков: текст, пояснение, код, диаграмма, симулятор, песочница, задача, тест, вопрос собеседования, ссылка на локальную лабораторию.

### 4.4 Общий движок симуляций (SimPlayer)
Все симуляторы строятся на одном ядре: состояние системы, шаги, лог событий, управление «играть, пауза, шаг вперёд, шаг назад, скорость, сброс, сценарий». Это даёт единое поведение, перемотку и возможность разбирать сценарий по шагам. Новый симулятор пишется как набор правил поверх этого ядра.

### 4.5 Песочницы
- **JS:** код выполняется в изолированном Web Worker с лимитом по времени. Набор тестов проверяет решение.
- **TypeScript:** проверка типов компилятором, затем запуск после удаления типов.
- **SQL:** PGlite с готовыми датасетами, сброс в одно нажатие, вывод плана запроса.
- **Мини-Redis:** собственная реализация набора команд на JS с виртуальным временем.

### 4.6 Эталонные результаты из реального Node
Скрипт на этапе сборки запускает примеры по event loop, streams и async в настоящем Node.js и записывает результат. Симулятор и режим «угадай вывод» сверяются с этим эталоном, поэтому мы не показываем порядок, придуманный вручную.

### 4.7 Локальные лаборатории
- Единый `docker-compose.yml`: PostgreSQL, Redis, RabbitMQ, Kafka (режим без ZooKeeper), веб-интерфейсы для просмотра очередей и топиков.
- Для каждой задачи: стартовый код, тесты (`npm test`), понятный результат «зелёный или красный».
- На сайте у каждой 💻-задачи есть карточка: требования, команды с кнопкой копирования, ожидаемый вывод, подсказки по шагам, решение скрыто до попытки.

### 4.8 Прогресс и заметки
- Прогресс уроков, задач и тестов хранится в браузере (`localStorage`), с кнопкой экспорта и импорта в файл, чтобы он не пропал.
- Заметки к урокам и поле для своих историй STAR (используются в модуле 14).
- Общая панель: прогресс по модулям, слабые темы по результатам тестов.

### 4.9 Поставка
Два варианта сборки:
1. **Один HTML-файл** (всё внутри): открывается двойным кликом, без сервера.
2. **Папка статического сайта** для публикации по ссылке.

Тяжёлые части (PGlite, компилятор TypeScript) подгружаются при первом открытии нужного урока. Для полностью офлайн-режима они могут быть включены в сборку.

## 5. Дизайн и пользовательский опыт

- Слева дерево модулей и уроков с отметками прогресса, сверху поиск.
- В уроке слой «коротко» (главное за минуту) и слой «подробно».
- Цветовая схема 🌐 / 💻 / 🔀 одинакова по всему сайту.
- Каждая симуляция подписана «модель» и содержит ссылку «проверить на реальной системе».
- Мобильная версия: симуляторы адаптируются, тяжёлые панели сворачиваются. Для практики с запуском команд основной сценарий рассчитан на компьютер.
- Режим «Собеседование»: ленточка в уроках с вопросами, которые могут задать, и эталонными формулировками.

## 8. Контроль качества

- **Достоверность:** факты по Node.js, PostgreSQL, Redis, Kafka, RabbitMQ сверяются с официальной документацией; по ШЭП и Kalkan только с официальными источниками. Неподтверждённое помечается «уточнить».
- **Автоматические проверки:** тесты движка симуляций, эталонные результаты примеров, прогон решений всех локальных задач.
- **Проверка интерфейса:** скриншоты и прогон основных сценариев в браузере после каждого этапа.
- **Самопроверка содержания:** в тестах каждый неверный вариант должен иметь понятное объяснение, почему он неверный.

## 9. Риски и как их закрываем

| Риск | Что делаем |
|---|---|
| Объём: около 70 уроков и десятки симуляторов | Вертикальный срез, общий движок, поэтапная выдача по приоритету |
| Симулятор может внушить ложное понимание | Пометка «модель», сверка с документацией, локальная проверка на реальной системе |
| Postgres в браузере: нет настоящей конкурентности | Изоляцию показываем сценарной моделью, настоящий опыт даём через два `psql` локально |
| Файл с тяжёлыми библиотеками слишком большой | Ленивая загрузка, раздельные сборки (один файл и папка) |
| Открытие по `file://` ограничивает загрузку модулей | Одно-файловая сборка |
| Kalkan и ШЭП недоступны для запуска в браузере | Модели и схемы в учебнике, реальная практика через NCANode и документацию локально |
| Устаревание версий и API | В материалах указываем актуальные LTS-версии на момент сборки, даты проверки источников |
| Прогресс в `localStorage` может исчезнуть | Экспорт и импорт прогресса в файл |

## 10. Что не входит в проект

- Реальный запуск NestJS, Kafka, RabbitMQ и Redis внутри браузера (даём модели и локальные лаборатории).
- Автоматическая оценка ответов мок-интервью искусственным интеллектом внутри сайта. Для этого есть рубрика самооценки, а развёрнутый разбор своих ответов можно приносить ко мне в чат.
- Серверная часть, аккаунты и синхронизация между устройствами.
