Существование тегов проверено на Docker Hub: `rabbitmq:4-management`, `apache/kafka:4.4.0`. Запуск образов не проверялся (в среде разработки нет Docker-демона). Проверка: `bash labs/scripts/smoke.sh`.

## Что проверено офлайн

- Функция `murmur2` и выбор партиции по ключу сверены с реализацией `kafkajs` на наборе ключей и с эталонными значениями из тестов Java-клиента Kafka (`21` → `-973932308`, `foobar` → `-790332482`, `a-little-bit-long-string` → `-985981536`).
- Назначение партиций стратегией roundRobin сверено с `RoundRobinAssigner` из `kafkajs`.
- Маршрутизация RabbitMQ (direct, fanout, topic) проверена по примерам из руководства RabbitMQ.
