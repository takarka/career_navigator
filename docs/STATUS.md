## Что НЕ проверено запуском (в среде разработки нет Docker-демона)

1. `labs/docker-compose.yml`: синтаксис и существование тегов образов проверены, **запуск нет**. Проверка: `bash labs/scripts/smoke.sh`.
2. Лаборатории на живых брокерах (`labs/m08/rabbitmq/*`, `labs/m08/kafka/*`): написаны по документации клиентов, синтаксис проверен, **на живых RabbitMQ и Kafka не запускались**. Проверка: `bash labs/scripts/run-broker-labs.sh` или workflow `oracle.yml`.
3. Оракул изоляции транзакций (`labs/m03/isolation`): сценарии выполняются на реальном PostgreSQL только в CI, **не запускался**. Модель проверена инвариантами.
4. Симуляторы RabbitMQ и Redis помечены «модель без оракула на живой системе».
5. Код с `ValidationPipe`/`class-validator`/`@nestjs/config`/ORM в уроках модуля 6 приведён по документации и не запускался.
6. Рабочие процессы GitHub Actions (`ci.yml`, `pages.yml`, `oracle.yml`) не запускались: первый прогон будет при первом push в `main` или PR.
