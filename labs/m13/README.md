# Capstone

- `capstone-starter/` — заготовка для собственного проекта: схема PostgreSQL, `docker-compose.yml`, список сценариев.
- `acceptance/` — приёмочные тесты HTTP-контракта (`POST /applications` с `Idempotency-Key`, `GET /applications/:id`, список с курсором, `cancel`). Запуск против вашего решения: `BASE_URL=http://127.0.0.1:3000 node acceptance/test.cjs`.
- `capstone-reference/` — эталон без фреймворков: SQLite (`node:sqlite`), Outbox, воркер отправки в `labs/m12/soap-mock`, ретраи, Fault, таймаут, rate limit, graceful shutdown, WebSocket `/ws`. Тест: `NODE_NO_WARNINGS=1 node capstone-reference/test.cjs`.
- `capstone-nest/` — эталон на NestJS: PGlite или настоящий PostgreSQL, Outbox, SOAP-мок, ретраи, rate limit, WebSocket `/ws`. Тест: `npx tsx --tsconfig labs/m13/capstone-nest/tsconfig.json labs/m13/capstone-nest/test.ts`. Для настоящего PostgreSQL: `cd labs && docker compose up -d --wait postgres`, затем `cd m13/capstone-nest && npm install && DATABASE_URL=postgres://lab:lab@localhost:5432/lab npm test`.

В `capstone-nest` при `AMQP_URL` (RabbitMQ) outbox публикуется в очередь с подтверждением, потребитель идемпотентен через таблицу inbox. Проверка: `cd labs && docker compose up -d --wait postgres rabbitmq`, затем `DATABASE_URL=… AMQP_URL=amqp://guest:guest@localhost:5672 npm test` в папке эталона. Вместо RabbitMQ можно указать Kafka: `KAFKA_BROKERS=localhost:9092` (ключ сообщения — идентификатор заявки, consumer group, топик на 3 партиции). Не реализовано: нагрузочный прогон. Их проверяйте своими тестами по чек-листу урока m13-l02. Эталоны смотрите после собственной попытки.
- `loadtest/` — нагрузочный прогон HTTP-контракта (autocannon, POST /applications с уникальным Idempotency-Key). Без `BASE_URL` поднимает `capstone-reference`: `cd labs/m13/loadtest && npm install && npm test`. Для своего решения: `BASE_URL=http://127.0.0.1:3000 npm test`. Параметры: `DURATION` (с), `CONNECTIONS`. Критерий: ни одной ошибки или не-2xx и p99 не выше 1000 мс. Проверено на эталоне: 43 770 запросов за 5 с, 0 ошибок, p99 8 мс (цифры зависят от машины).
