# Сценарии, которые нужно автоматизировать
- [ ] Повторный POST с тем же Idempotency-Key возвращает ту же заявку
- [ ] Брокер недоступен: заявка создаётся, событие уходит после восстановления (Outbox)
- [ ] Сообщение доставлено дважды: обработано один раз (inbox)
- [ ] SOAP Fault не повторяется, таймаут повторяется с задержкой, после лимита FAILED
- [ ] SIGTERM во время запроса: запрос завершён, код выхода 0
- [ ] Превышение rate limit: 429
